# POSEAI 開發現況

> 最後更新: 2026-07-07

---

## 專案定位

瀏覽器直接開啟的 AI 姿態分析工具，不需後端、不需 build、不需安裝任何套件。

---

## 技術棧

- **引擎**: `@mediapipe/pose` (classic API)
- **CDN**: `cdn.jsdelivr.net/npm/@mediapipe/pose/`（已驗證可用）
- **模型**: 自動下載 `pose_web.binarypb` (~7MB)
- **無後端、無 build step**

### 為何選 MediaPipe 而非其他

| | MediaPipe | OpenPose | YOLO Pose |
|---|---|---|---|
| 節點數 | **33** (含手腳掌) | 17 (COCO) | 17 (COCO) |
| 瀏覽器執行 | ✅ WASM+WebGPU | ❌ 不支援 | ❌ 不支援 |
| 速度 (瀏覽器) | ~**30 FPS** | — | — |
| 精度 COCO AP | ~78% | ~80% | ~75-82% |
| 多人支援 | 需加 detector | ✅ 原生多人 | ✅ 單模型多人 |
| 授權 | **MIT** ✅ | **非商業** ❌ | AGPL-3.0 |
| 跨平台 | ✅ 瀏覽器/手機/桌機 | ❌ 僅桌面 GPU | ❌ 需 Python |

**結論**: 要在瀏覽器即時跑且不建後端，MediaPipe 是唯一可行選擇。

## 已實作功能

### 核心
- MediaPipe 33 節點骨架即時偵測 + 鏡像視訊
- FPS 計數器
- 身體偵測覆蓋率（只算 visibility > 0.1 的節點）
- 局部身體支援（僅上半身時跳過膝蓋/重心）

### 三視角 × 12 項指標

#### 正面站姿 — 7 項
| ID | 指標 | 演算法 |
|----|------|--------|
| headLateralTilt | 頭部側偏 | 鼻樑偏離肩中線角度 |
| headRotation | 頭部旋轉 | 雙耳到鼻子 x 距離比 |
| shoulderLevel | 肩膀水平 | 左右肩高度差 |
| kneeVarusValgus | 膝內外翻 | 髖-膝-踝夾角偏離 180° |
| pelvicTilt | 骨盆傾斜 | 左右髂脊高度差 |
| spineCurve | 脊椎彎曲 | 鼻-肩中-髖中夾角偏離 180° |
| cogShift | 重心偏移 | 髖中投影偏離踝中線 |

#### 側面站姿 — 7 項
| ID | 指標 | 演算法 |
|----|------|--------|
| headTilt | 頭部前傾 | 耳-肩線與垂直線夾角 |
| shoulderProtraction | 肩膀前突 | 肩峰相對耳朵水平位移 |
| trunkLean | 軀幹前傾 | 肩中-髖中線與垂直線夾角 |
| pelvicTilt | 骨盆傾斜 | 髖-肩線與垂直線夾角 |
| kneeAngle | 膝關節角度 | 髖-膝-踝夾角 |
| ankleAngle | 踝關節角度 | 膝-踝-腳掌夾角 |
| cogShift | 重心偏移 | 髖中投影偏離踝中線 |

#### 深蹲模式 — 7 項
正面站姿全部 + **kneeTracking**（膝蓋投影偏離腳掌的水平量）

### 兩階段校正
| 模式 | 做法 | 精度 |
|------|------|------|
| 快速校正 | 45 幀取樣個人自然站姿為基準線 | 相對值 (偏差 Δ) |
| 鉛垂線校正 | 點兩個點標記背景垂直參考線，計算相機傾斜補償角 | 絕對值 |

鉛垂線流程：選模式 → 影片中央出現虛擬鉛垂線 → 在背景垂直參考線點 A(上) B(下) → 系統計算垂直偏差角並自動補償所有角度計算

### 錄影
- **快拍**: 節點檢查 → 5 秒倒數 → 截圖含骨架 → 分析面板
- **錄影**: MediaRecorder 錄 canvas stream (30fps) → 停止後自動下載 .webm

### 報告
- 報告 Modal 含當下截圖（含骨架）
- 匯出 CSV / JSON
- 如有校正基準線，包含偏差量

### HUD 浮層
影片左上角即時疊加所有指標數值（含顏色分級：綠/橙/紅）

### 信心度系統
- 每項指標旁顯示 🟢高 / 🟡中 / 🔴低
- 節點顏色隨信心度變化（green > 0.7 / orange > 0.5 / red < 0.5）
- 覆蓋率只算 visibility > 0.1 的節點

### 定位引導
- 開相機後顯示 checklist overlay
- 即時檢查：節點數、頭腳可見、平均信心度、距離

## 校正基準線原理

> 校正不是對齊地面或直線。MediaPipe 無法感知外部參考物。

校正記錄的是**使用者個人的自然站立姿勢**作為基準線，所有後續角度顯示偏差 (Δ)。

鉛垂線模式則透過使用者在背景標記垂直參考線（門框、牆角）計算相機傾斜補償角，讓數值更接近真實角度。

## 轉移方式

複製 `POSEAI/` 整個資料夾到新電腦，用瀏覽器開 `index.html` 即可。

不需 npm install、不需 build server、不需任何依賴安裝。
