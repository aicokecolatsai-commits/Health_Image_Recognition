# POSEAI — 姿態分析工具

## 檔案結構

```
POSEAI/
├── index.html          (17 KB)  → 頁面結構
├── style.css           (12 KB)  → 暗色主題 UI
├── app.js              (51 KB)  → 全部邏輯
└── model/
    └── pose_landmarker_lite.task  (5.5 MB)  → 備用離線模型
```

## 啟動方式

直接用瀏覽器開啟 `index.html`（需網路，CDN 載入模型 ~7MB）

## 技術棧

- **引擎**: `@mediapipe/pose` (classic API, jsDelivr CDN)
- **模型**: CDN 自動下載 `pose_web.binarypb`（~7MB）
- **CDN**: `cdn.jsdelivr.net/npm/@mediapipe/pose/`（已驗證可用）
- **無後端、無 build step**

## 已實作功能

### 核心
- MediaPipe 33 節點骨架即時偵測
- 鏡像視訊 + 骨架 overlay
- FPS 計數器
- 身體偵測覆蓋率（只算 visibility > 0.1 的節點）
- 局部身體支援（僅上半身時跳過膝蓋/重心，其餘照常）

### 三視角指標 (2026-07-07)
每切換視角僅顯示對應指標卡片（data-views attribute 控制隱藏）

#### 正面站姿 — 7 項
| ID | 指標 | 演算法 |
|----|------|--------|
| headLateralTilt | 頭部側偏 | 鼻樑偏離肩中線角度 |
| headRotation | 頭部旋轉 | 雙耳到鼻子 x 距離比 → 旋轉角 |
| shoulderLevel | 肩膀水平 | 左右肩高度差 atan2 |
| kneeVarusValgus | 膝內外翻 | 髖-膝-踝夾角偏離 180° |
| pelvicTilt | 骨盆傾斜 | 左右髂脊高度差 |
| spineCurve | 脊椎彎曲 | 鼻-肩中-髖中夾角偏離 180° |
| cogShift | 重心偏移 | 髖中投影偏離踝中線 |

#### 側面站姿 — 8 項
| ID | 指標 | 演算法 |
|----|------|--------|
| headTilt | 頭部前傾 | 耳-肩線與垂直線夾角 |
| shoulderProtraction | 肩膀前突 | 肩峰相對耳朵水平位移量 |
| trunkLean | 軀幹前傾 | 肩中-髖中線與垂直線夾角 |
| pelvicTilt | 骨盆傾斜 | 髖-肩線與垂直線夾角 |
| kneeAngle | 膝關節角度 | 髖-膝-踝夾角 |
| ankleAngle | 踝關節角度 | 膝-踝-腳掌夾角 |
| spineCurve | 脊椎彎曲 | 鼻-肩中-髖中夾角偏離 180° |
| cogShift | 重心偏移 | 髖中投影偏離踝中線 |

#### 深蹲模式 — 9 項
正面站姿全部 + **trunkLean**（軀幹前傾）+ **kneeTracking**（膝蓋投影偏離腳掌的水平量）

### 兩階段校正 (2026-07-07)
| 模式 | 做法 | 精度 |
|------|------|------|
| **快速校正** | 45 幀取樣個人自然站姿為基準線 | 相對值（偏差 Δ） |
| **鉛垂線校正** | 點兩個點標記背景垂直參考線，算出相機傾斜補償角 | 絕對值 |

鉛垂線校正流程：選擇模式 → 影片中央出現虛擬鉛垂線 → 在背景垂直參考線點 A(上)、B(下) → 系統計算垂直偏差角並自動補償所有角度計算

### 錄影
- **快拍**：節點檢查 → 5 秒倒數 → 截圖含骨架 → 分析面板
- **錄影**：MediaRecorder 錄 canvas stream (30fps) → 停止後自動下載 .webm

### 報告
- 報告 Modal 含當下截圖（含骨架）
- 匯出 CSV / JSON
- 如有校正基準線，報告包含偏差量

### HUD 浮層
影片左上角即時疊加所有指標數值（含顏色分級：綠/橙/紅）

### 信心度
- 每項指標旁顯示 🟢高 / 🟡中 / 🔴低
- 節點顏色隨信心度變化（綠色>0.7 / 橙色>0.5 / 紅色<0.5）
- 覆蓋率只算 visibility > 0.1 的節點

### 定位引導
- 開相機後顯示 checklist overlay
- 即時檢查：節點數、頭腳可見、平均信心度、距離

## 校正基準線說明

校正不是對齊地面或直線。MediaPipe 無法感知外部參考物。
校正記錄的是**使用者個人的自然站立姿勢**作為基準線：

```
例：平常頭微偏右 3°，校正後偏右 5° → 顯示 Δ +2.0°
```

鉛垂線模式透過使用者在背景標記垂直參考線來計算相機傾斜補償角，實現更接近真實的角度值。

## 畫面角度標註

已在 canvas 上繪製：
- 側面：頭部前傾弧 + H:xx.x°，膝關節弧 + K:xx.x°
- 正面：肩膀水平 S:xx.x°
- HUD：所有指標即時數值疊加在左上角
- 鉛垂線模式：垂直參考線（藍虛線）、標記點 A/B、校正後綠線
